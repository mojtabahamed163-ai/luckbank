# بنك الحظ 1.0.5

- تكبير مساحة خانات اللوحة قليلًا وتقليص الوسط، مع الحفاظ على تخطيط الأربعين خانة.
- استبدال الخط المزخرف بخط Noto Sans Arabic الواضح والمضمّن داخل المشروع.
- تبسيط وسط لوحة اللعب إلى اسم صاحب الدور، الجولة، الرصيد، المرحلة، الموقع والنرد والإجراء الأساسي.
- نقل السوق والتطوير والتفاوض والسجل والقواعد وإنهاء المباراة إلى قائمة «المزيد».
- جعل زر «الدول» يعرض دول اللاعب صاحب الدور فقط، مع تفاصيل دوله واستثماراته؛ تفاصيل كل خانة أصبحت صفحة منفصلة.
- تحديث ترجمات الواجهة العربية والإنجليزية والإسبانية والفرنسية.
