# تقرير التحقق — بنك الحظ 1.0.5

## الاختبارات

- اختبارات قواعد اللعبة والاقتصاد: **1265/1265 ناجحة**.
- اختبار الواجهة على دقة 1280×720: نجح في العربية والإنجليزية والإسبانية والفرنسية.
- شمل اختبار الواجهة لوحة الأربعين خانة، ظهور قرار الشراء كاملًا، عرض ممتلكات اللاعب الحالي فقط، قائمة «المزيد»، وتفاصيل الخانة.

## حزمة Android

- الحزمة: `org.manus.luckbank`.
- اسم الإصدار: `1.0.5`؛ رقم الإصدار Android: `6`، لتثبيت التحديث فوق الإصدار السابق ذي الرقم `5`.
- الحد الأدنى Android API 24، والاتجاه أفقي.
- APK موقّع، ويتضمن معماريتي ARM64 وARMv7.
- لا يطلب إذن الإنترنت. الحجم نحو 70 ميغابايت.
- تم التحقق من بيانات الحزمة والتوقيع والمعماريات بعد التصدير.

لم يتم تثبيت الإصدار على هاتف Infinix SMART 7 HD فعليًا داخل بيئة البناء؛ لذلك يُرجى اختبار APK على الهاتف للتأكد النهائي من التجربة على الجهاز.
