# اختبار بنك الحظ 1.0.2

- إضافة اللعب المحلي بالتناوب من لاعبين إلى أربعة لاعبين إلى جانب اللعب ضد الكمبيوتر.
- توضيح مواقع اللاعبين وعلاماتهم، وإظهار اسم المحطة والدولة وسعرها وإيجارها ومالكها في بطاقة الموقع.
- توسيع APK ليضم ARMv7 وARM64 لمعالجة عدم توافق بعض الأجهزة.
- يحافظ الإصدار على العمل دون اتصال ولا يطلب إذن الإنترنت.
- اختبارات المشروع: قواعد اللعبة 84/84، تفاعلات الواجهة 33/33، واستعادة الحفظ 7/7.
- توقيع APK Debug للتثبيت اليدوي؛ لا يتضمن اختبار تثبيت على هاتف فعلي.

الملفات المرفقة: `luckbank-universal-debug.apk` للتثبيت، و`luckbank-source.zip` لفتح المصدر والأصول والاختبارات في Godot 4.7.2.
