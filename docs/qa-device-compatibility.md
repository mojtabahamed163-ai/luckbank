# تقرير فحص توافق شاشات الهواتف

## النطاق

تم فحص واجهة اللعبة على مقاسات أفقية تمثل شاشات هواتف صغيرة ومتوسطة وعالية الدقة. إعداد المشروع يثبت اتجاه Android على الوضع الأفقي (`landscape`) ويستخدم `canvas_items` مع `aspect="expand"`.

## المقاسات التي اجتازت الفحص

| المقاس | النتيجة | ما تم التحقق منه |
|---|---|---|
| 640×360 | PASS | إعداد المباراة، اللوحة، الخانات الأربعون، القوائم، التفاصيل، النرد واللغات الأربع |
| 854×480 | PASS | نفس الفحوص مع مساحة عمودية محدودة |
| 1280×720 | PASS | المرجع الأساسي للواجهة |
| 1920×1080 | PASS | التمدد إلى شاشة أفقية عالية الدقة |

الفحص الآلي يتحقق من أن الخانات الأربعين تقع داخل سطح اللوحة، وأن إحداثيات الحلقة لا تتكرر، وأن اللوحة المركزية لا تتداخل مع الخانات، وأن نصوص وأسعار الخانات الخاصة 13 و15 و35 والسجن 30 داخل حدود خاناتها. كما يتحقق من ظهور أعلام السودان ومصر بالترتيب الصحيح، وظهور «غرامة 500 وحدة» في السجن، و«الدورات» دون عرض المتبقي.

## أوامر إعادة الفحص

```bash
# فحص القواعد والاقتصاد
source /home/ubuntu/.user_env
godot --headless --path . --scene res://test/test_suite.tscn

# فحص الواجهة على مقاس محدد
xvfb-run -a -s '-screen 0 1400x900x24' \
  godot --audio-driver Dummy --path . \
  --resolution 1280x720 --windowed \
  --script res://test/ui_smoke.gd
```

لتكرار فحص المقاسات، استبدل `--resolution` بالقيم الأربع المذكورة أعلاه. آخر نتيجة موثقة: اختبارات القواعد والاقتصاد **1448/1448**، واختبار الواجهة ناجح في المقاسات الأربعة واللغات العربية والإنجليزية والإسبانية والفرنسية.

## حدود الفحص

الفحص تم على Xvfb/Godot وليس على أجهزة Android فعلية. لا يدّعي التقرير قياس حرارة الهاتف أو استهلاك البطارية أو معدل الإطارات على طراز هاتف محدد. التطبيق مقفل أفقيًا حسب إعداد المشروع؛ اختبار الوضع العمودي ليس ضمن النطاق المقصود.
