# بنك الحظ 1.0.4

## الجديد

- توسيع اللوحة إلى 40 خانة و30 دولة، مع أسعار شراء وإيجار ودخل دوري ثابتة ومراجعة بالاختبارات.
- إضافة ست مجموعات دولة، وثلاثة مستويات تطوير، واستثمارات قابلة للشراء، وتوسعات زراعية وحيوانية مدفوعة في السودان.
- إضافة ضرائب وسوق وأحداث اقتصادية، وإدارة العجز والتصفية والإفلاس والصفقات، وذكاء اصطناعي بثلاث درجات.
- إضافة لعب محلي من لاعبين إلى أربعة، واستكمال المباراة المحفوظة، ودعم العربية والإنجليزية والإسبانية والفرنسية.
- إعادة تصميم اللعب إلى لوحة محيطية Landscape للهاتف مع منطقة معلومات مركزية، وتسجيل صور شاشة من المباراة.

## Android

ملف APK Debug موقع، بمعماريتي ARM64 وARMv7، والحد الأدنى Android API 24، ولا يطلب إذن الإنترنت. اتجاه Manifest أفقي. التوقيع v2/v3 وفحص ZIP نجحا. صدّر Godot مع تحذير توافق واستخدم Build-Tools 29.0.3 بديلًا لعدم توفر نسخة مطابقة لـTarget SDK 36. الحزمة للاختبار اليدوي وليست إصدار متجر.

الاختبارات: 1257/1257 في القواعد والاقتصاد، وفحص واجهات X11 نجح عند 1280×720 للعربية والإنجليزية والإسبانية والفرنسية. لم يتصل هاتف أو محاكي؛ لذلك لم يُختبر التثبيت الفعلي أو اللمس. التوافق المتوقع مع Infinix SMART 7 HD مبني على المواصفات المنشورة فقط.

## أصول الإصدار

تتضمن صفحة الإصدار APK، وZIP للمصدر والاختبارات، وZIP لصور اللعبة. صور اللوحة والرمي والشراء محفوظة أيضًا في `docs/screenshots/v1.0.4/`.
